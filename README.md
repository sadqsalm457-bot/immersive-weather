# IMMERSIVE WEATHER — تطبيق طقس عربي / English

تطبيق طقس أصلي لنظام Android مبني باستخدام **Kotlin وJetpack Compose**. يدعم واجهة عربية كاملة باتجاه RTL وواجهة إنجليزية LTR، ويجلب بيانات الطقس الحقيقية من Open-Meteo. المشروع مجهّز لبناء APK عبر GitHub Actions.

> هذه نسخة تطبيق عملية موسّعة، وليست مجرد نموذج واجهة. مع ذلك، بعض الميزات المتقدمة المذكورة في وثيقة الفكرة تحتاج مزوّد بيانات أو تطويراً إضافياً، وهي موضحة في قسم «الميزات والحدود» أدناه بدلاً من عرض بيانات وهمية.

## المزايا المنفذة

- واجهة عربية وإنجليزية مع التحويل من داخل الإعدادات.
- اتجاه RTL/LTR حسب اللغة.
- اختيار الأرقام العربية أو الغربية.
- درجات الحرارة °C/°F وسرعة الرياح km/h أو m/s.
- خلفية جوية متحركة تتبدل حسب حالة الطقس والليل/النهار ودرجة الحرارة.
- مؤثرات Canvas للشمس والسحب والمطر والثلج والبرق.
- بيانات الطقس الحالية: الحرارة، المحسوسة، الرطوبة، الرياح واتجاهها وهباتها، الضغط، الرؤية، نقطة الندى، UV، الغيوم والهطول.
- توقعات الساعات الـ24 القادمة مع مخطط درجات الحرارة واحتمال الهطول والرياح.
- توقعات 7 أيام مع احتمال الهطول وUV والشروق والغروب.
- جودة الهواء عند توفرها من Open-Meteo Air Quality.
- تحديد موقع تقريبي عبر إذن GPS عند توفر آخر موقع معروف، مع مدينة افتراضية وإمكانية البحث اليدوي.
- البحث عن المدن وحفظ المدن المفضلة محلياً على الجهاز.
- خريطة تفاعلية مع طبقة رادار المطر الحالية وتشغيل إطارات الرادار السابقة من RainViewer.
- إعدادات اللغة والوحدات والأرقام والسمة الفاتحة/الداكنة/التلقائية والحركة وتوفير البطارية.
- حالات تحميل وخطأ واتصال، مع إمكانية إعادة المحاولة.
- أيقونة Android تكيفية ونسخة أحادية اللون للأجهزة المدعومة.
- GitHub Actions لبناء Debug APK، وبناء Release APK موقع عند إضافة أسرار التوقيع.

## التقنية

- Kotlin، Android SDK، Jetpack Compose، Material 3.
- Minimum SDK 26؛ يستهدف Android 15 SDK مع compileSdk 36 للتوافق مع أجهزة Android 16.
- Java 17، Android Gradle Plugin 8.10.1، Gradle 8.11.1، Kotlin 2.1.20.
- Open-Meteo Forecast API وGeocoding API وAir Quality API.
- RainViewer لرادار الأمطار، وOpenStreetMap لخلفية الخريطة.

## بناء APK من GitHub

1. أنشئ مستودعاً جديداً باسم `immersive-weather`.
2. اجعله Public إذا أردت نشر المشروع كمصدر مفتوح.
3. ارفع **محتويات** هذا المجلد، بما فيها مجلد `.github` المخفي، إلى جذر المستودع.
4. افتح تبويب **Actions**.
5. اختر **Android APK Build** ثم **Run workflow**، أو انتظر البناء التلقائي بعد رفع الملفات إلى `main`.
6. بعد نجاح البناء افتح تشغيل الـ workflow، وانزل إلى **Artifacts**.
7. نزّل `immersive-weather-debug-apk`، ثم فك ضغطه وثبّت APK على هاتف Android.

لا يحتاج بناء Debug إلى مفتاح API أو بيانات سرية.

## توقيع نسخة Release

لا ترفع ملف keystore أو كلمات مروره إلى المستودع. أنشئ مفتاح توقيع واحتفظ بنسخة احتياطية آمنة. أضف الأسرار التالية من:

**Repository → Settings → Secrets and variables → Actions → New repository secret**

- `SIGNING_KEY_BASE64`: ملف keystore كاملاً بعد تحويله إلى Base64.
- `SIGNING_STORE_PASSWORD`: كلمة مرور مخزن المفاتيح.
- `SIGNING_KEY_ALIAS`: اسم المفتاح.
- `SIGNING_KEY_PASSWORD`: كلمة مرور المفتاح.

بعد إضافة الأسرار الأربعة، سيبني الـ workflow نسخة Release موقعة ويرفعها كـ Artifact منفصل. احتفظ بنفس ملف keystore واسم alias وكلمات المرور للإصدارات المستقبلية؛ تغيير مفتاح التوقيع يمنع تحديث النسخة المثبتة كتحديث عادي.

## تشغيل محلياً

يتطلب Android Studio حديثاً وJDK 17 وAndroid SDK Platform 36. افتح مجلد المشروع في Android Studio وانتظر Gradle Sync، ثم شغّل التطبيق على جهاز حقيقي أو محاكي. لبناء Debug APK من الطرفية بعد توفر Gradle:

```bash
gradle --no-daemon :app:assembleDebug
```

ملف APK الناتج:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## مصادر البيانات والخصوصية

- الطقس والتوقعات والبحث عن المدن وجودة الهواء: [Open-Meteo](https://open-meteo.com/).
- خريطة الأساس: [OpenStreetMap](https://www.openstreetmap.org/).
- طبقة رادار المطر: [RainViewer](https://www.rainviewer.com/).
- لا توجد مفاتيح API سرية مضمنة في المشروع.
- إذن الموقع اختياري؛ عند رفضه يمكن استخدام المدينة الافتراضية أو البحث اليدوي.
- بيانات الموقع تُستخدم لجلب الطقس، ولا يرسل التطبيق سجل مواقع إلى خادم خاص به.

## الميزات التي لم تُنفذ بعد

- تنبيهات الطقس الرسمية متعددة الدول: لم يتم ربط مزود تحذيرات رسمي، لذلك لا يعرض التطبيق تحذيرات مختلقة.
- أطوار القمر وحساب الإضاءة القمرية، ومعلومات حبوب اللقاح: غير متاحة في مصادر البيانات الحالية المستخدمة.
- طبقات الخريطة الإضافية للرياح والحرارة والغطاء السحابي وصور الأقمار الصناعية؛ المتوفر حالياً رادار المطر وخريطة الأساس.
- أصوات الرعد، تراكم الثلوج، وتفاعلات قطرات الماء فوق البطاقات الزجاجية.
- تخزين دائم لآخر قراءة طقس للعمل دون اتصال؛ عند فشل الشبكة تظهر رسالة خطأ بدلاً من اختلاق بيانات حديثة.
- التنبؤ الدقيق بموعد بدء/انتهاء المطر والتنبيهات الدقيقة يتطلب مزوداً متخصصاً وتغطية مكانية مناسبة.
